# Smart Moving (Fabric 1.20.1 / 1.21.8 / 26.3)

Divisor의 **Smart Moving** (Forge/ModLoader, 마지막 버전 16.3 for MC 1.8.9)을 Fabric으로 옮긴 프로젝트입니다.
움직임 공식과 기본값은 원작 16.3 소스 코드에서 가져왔습니다.

## 지원 버전

마인크래프트 jar 는 버전마다 따로입니다. 자기 게임 버전에 맞는 jar 하나를 Fabric API 와 함께 `mods` 폴더에 넣으세요.

| 마인크래프트 | jar | Java | 비고 |
|---|---|---|---|
| 1.20.1 | `smartmoving-fabric-2.0.0+1.20.1.jar` | 17+ | 모드가 가장 많은 버전 |
| 1.21.8 | `smartmoving-fabric-2.0.0+1.21.8.jar` | 21+ | |
| 26.3 | `smartmoving-fabric-2.0.0+26.3.jar` | 25+ | 최신 버전 (모장 공식 이름 사용) |

기능은 세 버전 모두 같습니다.

## 조작 (원작 Smart Moving 16.3 기준)

**잡기 = 달리기 키(기본 왼쪽 Ctrl).** 원작은 두 키의 기본값이 같았습니다. 따로 쓰고 싶으면 `옵션 → 조작 → Smart Moving → 잡기`에 키를 지정하고 설정에서 `grabUsesSprintKey`를 `false`로 바꾸세요.

| 동작 | 조작 | 설명 |
| --- | --- | --- |
| 달리기 | **Ctrl** 누른 채 앞으로 | 걷기의 1.5배 (바닐라는 1.3배). 지침이 쌓임. W 두 번 달리기는 바닐라 속도, 지침 없음 |
| 달리기 점프 | 달리면서 점프 | 지금 수평 속도 × 2 (상한 있음). 지침 65 |
| 슬라이딩 | 달리면서 **Ctrl + Shift** | 앞으로 튀어나가며 미끄러짐 (얼음 위에서 더 멀리). 좌우 키로 방향 조절. Shift를 떼면 끝, 느려지면 기어가기로 |
| 헤드 점프 | 달리면서 **Ctrl + 점프를 누르고 있다가 뗌** | 머리부터 날아감. 짧게 누를수록 납작하고, 0.5초(10틱) 이상이면 일반 점프 높이 |
| 모아 뛰기 | 제자리에서 **Shift + 점프를 누르고 있다가 뗌** | 최대 1초(20틱) 충전, 1.3배 높이 |
| 기어가기 | **Shift 누른 채 Ctrl** 누르기 (또는 Z로 켜기/끄기) | Shift를 떼면 일어섬 (공간이 없으면 계속) |
| 벽 타기 | 잡을 곳(블록 모서리·반블록·계단·울타리 등)을 보고 **Ctrl** 유지 | 앞 = 오르기, 앞키 떼기 = 내려가기, 좌우 = 옆. 평평한 벽은 못 탐 (원작과 같음) |
| 벽 타며 점프 | 꼭대기에 매달려 점프 / **Shift** 로 매달린 채 점프 | 위로 뛰어오르기 / 벽을 박차고 뒤로 (Ctrl 유지 = 헤드 점프) |
| 벽차기 | 공중에서 **점프 두 번** 누르고 누른 채로 벽에 부딪힘 | 들어온 각도의 반대로 튕겨 나감. 점프를 계속 누르면 다음 벽에서도 이어서 튕김. Ctrl 유지 = 헤드 점프. 2칸 넘게 떨어지는 중엔 불가 |
| 틈으로 기어 오르기 | 벽에 매달린 채 **Ctrl + Shift + 앞** (위에 1칸 높이 틈이 있을 때) | 윗몸을 틈으로 밀어 넣고 들어가서 기어감 |
| 기어서 턱 오르기 | 기어가면서(또는 슬라이딩하다가) 잡을 곳을 보고 **Ctrl + Shift + 앞** | 납작한 자세 그대로 턱을 오름. 몸 아래가 비면 일어섬 |
| 천장 매달리기 | **철창이나 닫힌 다락문** 바로 아래에서 **Ctrl** 유지 (Shift는 떼고) | 매달려서 천천히 이동. 손을 떼면 떨어짐 |
| 옆/뒤 점프 | 땅에서 **A·D·S를 빠르게 두 번** | 그쪽으로 낮게 뜀. 옆+뒤를 같이 두 번 누르면 대각선 뒤로 |
| 헤엄치기 | 깊은 물에서 앞으로 | 머리를 물 위에 내놓고 평영. 수면 높이에 맞춰 떠 있음. Shift = 아래로, Ctrl = 빠르게. 물가 벽에 대고 점프하면 물 밖으로 뛰어오름 |
| 잠수 | 물속에서 | 보는 방향(위아래 포함)으로 나아감. 점프 = 위로, Shift = 아래로, 가만히 있으면 그 자리에 떠 있음 |
| 원작 비행 | 크리에이티브 비행 중 | 보는 방향으로 날고 몸은 엎드린 자세. 점프/Shift = 위/아래, Ctrl = 빠르게 |
| 빠른 사다리 | 사다리에서 앞키 | 바닐라보다 빠르게 올라감 |

### 여우 무빙

원작 코드에서 확인한 핵심 규칙은 두 가지입니다.

1. **슬라이딩하다가 공중에 뜨면 "활공"으로 바뀝니다.** 공기 저항이 거의 없습니다 (감속 0.999/틱, 일반 점프는 0.91).
2. **Ctrl + Shift를 누른 채 착지하면** 속도를 그대로 살려서 다시 슬라이딩합니다.

그래서 **달리기 → Ctrl+Shift(슬라이딩) → 점프 → (활공) → Ctrl+Shift 누른 채 착지 → 점프 → …** 로 이어가면
처음 슬라이딩 속도를 거의 잃지 않고 계속 날아갑니다. 슬라이딩에서 뛰는 점프는 지침이 들지 않고, 처음 슬라이딩할 때만 지침 10이 듭니다.
내리막에서 슬라이딩하면 턱마다 저절로 활공합니다.

### 지침 (원작 exhaustion)

행동하면 올라가고 쉬면 내려갑니다. 배고픔 줄 위에 **번개 아이콘**으로 남은 체력이 표시됩니다.

- 행동마다 "이 값 이하일 때만 시작"과 "이 값을 넘으면 중단" 기준이 따로 있습니다. 회색 번개는 지금 하려는 행동에 필요한 만큼을 나타냅니다.
- 회복 속도는 가만히 서 있을 때 2배, 공중에서 2.5배이고 달리는 중에는 회복되지 않습니다.
- 배고픔이 4칸 이하면 회복되지 않습니다.

모아 뛰기와 헤드 점프 충전량은 체력 줄 위에 **파란 다이아**로 표시됩니다.

## 원작과 다른 점

- **벽 타기**: 원작의 손/발 잡기 판정(Orientation)과 속도 규칙을 그대로 옮겼습니다.
- **틈으로 기어 오르기**: 원작은 충돌 상자의 아래 1칸을 잘라냈습니다. 이 포트는 바닐라의 납작한 자세(높이 0.6)를 쓰고 몸을 1칸 올려 같은 자리에 둡니다. 그래서 상자가 원작(0.8)보다 조금 낮습니다.
- **수영/잠수**: 원작은 헤엄칠 때도 충돌 상자를 납작하게 했습니다. 이 포트는 수면에서 헤엄칠 때는 서 있는 상자(머리가 물 위), 잠수할 때만 납작한 자세를 씁니다. 그래서 수면에서 헤엄칠 때 몸이 원작처럼 눕지 않고 서서 헤엄치는 모습입니다. 용암 속 수영은 원작 기본값처럼 꺼져 있습니다.
- **원작 비행**: 바닐라 엘리트라처럼 납작한 자세를 몸 위치 그대로 씁니다. 땅에 닿으면 바닐라처럼 비행이 끝납니다.
- **애니메이션**: 원작 Smart Render 의 팔·다리·머리 공식을 옮겼습니다. 원작은 몸통을 여러 조각으로 나눠 따로 돌렸는데 바닐라 모델에는 그런 조각이 없어서, 몸 전체의 기울기는 바닐라의 엎드린 자세에 맡깁니다.
- **지침이 배고픔으로 바뀌는 부분**: 원작은 지침이 회복될 때 배고픔을 조금 소모했습니다. 이 포트에는 없습니다.

## 설정

처음 실행하면 `config/smartmoving.json`이 생깁니다. 각 기능 on/off, 지침 수치, 점프 배율 등을 바꿀 수 있습니다.
기본값은 원작의 기본 설정과 같고, 각 항목 옆 주석에 원작 설정 키 이름을 적어 두었습니다.

## 멀티플레이

**서버와 클라이언트 모두에 설치해야 합니다.** 서버에 모드가 없으면 클라이언트 기능이 자동으로 꺼집니다
(자세·낙하 대미지 판정이 서버와 어긋나는 것을 막기 위함).

## 빌드

버전마다 독립된 Gradle 프로젝트가 `versions/<마인크래프트 버전>/` 에 있습니다.

```
cd versions/1.21.8      # 또는 versions/1.20.1, versions/26.3
./gradlew build
```

JDK 는 1.20.1·1.21.8 은 21, 26.3 은 25 가 필요합니다.
결과물: `versions/<버전>/build/libs/smartmoving-fabric-<버전>.jar` → `.minecraft/mods`에 Fabric API와 함께 넣으면 됩니다.
GitHub Actions에서도 푸시할 때마다 세 버전이 모두 빌드되며, Actions 탭의 `smartmoving-fabric-<마인크래프트 버전>` 아티팩트에서 jar를 받을 수 있습니다.

게임에서 바로 테스트: 해당 버전 폴더에서 `./gradlew runClient`

## 코드 구조

아래는 `versions/1.21.8` 기준입니다. 다른 버전도 파일 구성은 같고, 마인크래프트 쪽 이름만 그 버전에 맞게 다릅니다.

```
src/main/java/com/smartmoving/        (서버+클라이언트 공용)
  SmartMoving.java                    진입점
  config/SmartMovingConfig.java       설정 파일
  state/SmartMovingState.java         플레이어별 상태 (기어가기/벽타기/슬라이딩/헤드점프/지침 ...)
  state/SmartMovingPlayer.java        PlayerEntity 에 상태를 붙이는 인터페이스
  logic/MovementPhysics.java          슬라이딩·헤드 점프 물리 (바닐라 travel 대체)
  logic/climb/FreeClimbing.java       벽 타기 (원작 handleClimbing)
  logic/climb/Orientation.java        손/발로 잡을 곳 찾기 (원작 Orientation)
  logic/WallProbe.java                일어설 공간이 있는지 검사
  logic/SmartSwimming.java            수영·잠수 (원작 handleSwimming)
  logic/SmartFlying.java              원작 비행 (원작 handleAlternativeFlying)
  logic/MoveFlying.java               보는 방향으로 가속 (원작 moveFlying)
  logic/Jumps.java                    원작 tryJump 포트 (모든 점프 공식)
  logic/Exhaustion.java               원작 지침 계산
  network/                            클라이언트↔서버 상태 동기화 패킷
  mixin/PlayerEntityMixin.java        자세 강제, 수영·비행 가로채기, 벽 잡을 때 낙하 대미지
  mixin/LivingEntityMixin.java        travel 가로채기, 바닐라 점프 대체, 달리기 속도, 헤드 착지 대미지

src/client/java/com/smartmoving/client/ (클라이언트 전용)
  SmartMovingClient.java              진입점 (키, HUD, 패킷 수신)
  ClientMovementController.java       키 입력 → 상태 결정 (핵심 로직)
  ExhaustionHud.java                  원작 HUD (번개 = 지침, 다이아 = 점프 충전)
  ClimbCrawling.java                  틈으로 기어 오르기 / 기어서 턱 오르기
  SmartAnimations.java                원작 Smart Render 애니메이션 공식
  mixin/ClientPlayerEntityMixin.java  매 틱 컨트롤러 호출, 지치면 달리기 금지
  mixin/BipedEntityModelMixin.java    원작 애니메이션 적용 (SmartAnimations)
```
